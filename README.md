## Priority Scheduling Algorithm (C)

This project implements the **Non-Preemptive Priority Scheduling Algorithm** using the C programming language.

### Description
- Each process has:
  - Process ID
  - Burst Time
  - Priority
- The process with the **lowest priority number executes first**
- Waiting Time and Turnaround Time are calculated for each process
- Average Waiting Time and Average Turnaround Time are displayed

### Algorithm Type
- Priority Scheduling
- Non-Preemptive
- Lower number = Higher priority

### Language
- C (C99 standard)

### Output
The program displays a table containing:
- PID
- Burst Time
- Priority
- Waiting Time
- Turnaround Time
